- اسم اللاعب يحدد عند الإنشاء/الدخول، مع منع التعارض تلقائياً بإضافة رقم.
- الهوست يختار الفئة وعدد برا السالفة.
- كل لاعب يسأل مرتين، والدور يتحكم فيه السيرفر.
- التصويت بعد انتهاء الأسئلة أو بقرار الهوست.
- نقاط محفوظة داخل نفس الغرفة، مع جولة جديدة بدون إعادة إدخال الكود.
- تم اختبار بناء JavaScript وصيغة المشروع محلياً.
